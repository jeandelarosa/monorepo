# 3D Catalog - Monorepo

**Autor:** Jean Sebastian de la Rosa Escobedo  
**Año:** 2026

## Descripción

Catálogo 3D interactivo de componentes para PC con autenticación JWT, base de datos Supabase y renderizado 3D con Three.js.

## Stack Tecnológico

### Backend
- **Node.js** con Express.js
- **Supabase** (PostgreSQL)
- **JWT** para autenticación
- **bcrypt** para encriptación de contraseñas

### Frontend
- **Svelte** (framework reactivo)
- **Vite** (bundler)
- **Tailwind CSS** (estilos)
- **Three.js** (renderizado 3D)
